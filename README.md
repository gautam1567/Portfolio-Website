# Gautam Singh Yadav - Portfolio

Responsive personal portfolio website built with HTML, CSS and JavaScript.

## Features
- Responsive navigation and project grid
- Light/dark theme toggle
- Typed text animation
- ScrollReveal animations
- Accessible image alt text and external-link handling
- Functional contact form using FormSubmit

## Contact form
The contact form is configured for `gautamyadav1567@gmail.com` through FormSubmit. On the first submission, FormSubmit may require email activation/confirmation before messages are delivered.

## Files
- `index.html` - Portfolio markup
- `style.css` - Styling and responsive layout
- `script.js` - Navigation, theme toggle, typed text and animations
- `110.pdf` - Resume
